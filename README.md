# フランス語 会話練習アプリ

教材（テキスト・教科書のページ写真）をアップロードすると、その内容をもとにAIがフランス語で会話練習の相手をしてくれるアプリです。

## 機能

- テキストファイル（.txt / .md）または写真のアップロード（写真はAIが文字を読み取ってテキスト化）
- アップロードした教材から自動でボキャブラリー（単語・表現）を抽出し、蓄積
- 教材中の文法解説（教科書の「Grammaire」欄など）をAIが日本語でわかりやすく解説
- レベル（初級 / 中級 / 上級）に応じて会話の難易度と、蓄積ボキャブラリーの復習頻度を調整
- AIとの会話練習（フランス語での返答 + 日本語訳 + 文法の添削）

## セットアップ

```bash
npm install
```

`.env.local` を作成し、以下を設定してください（`.env.example` を参照）:

```
OPENAI_API_KEY=sk-...
OPENAI_VISION_MODEL=gpt-4.1
OPENAI_CHAT_MODEL=gpt-4.1
```

## 起動

```bash
npm run dev
```

`http://localhost:3000` を開いてください。

## デプロイ（Vercel）

1. このリポジトリをVercelでImport
2. Environment Variables に上記3つを設定
3. Deploy

デプロイ後、発行されたURLをiPhone/iPadのSafariで開き、共有 →「ホーム画面に追加」でアプリのように使えます（PWA対応）。

## データの保存について

ボキャブラリーバンク・教材テキストは、ブラウザの localStorage に保存されます。ログイン機能・サーバー側データベースは無いため、**この端末・このブラウザ内でのみ**蓄積されます。他の端末とは共有されません。
